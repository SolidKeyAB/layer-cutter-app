# Layer Cutter

SolidKey's web tool for turning a hand-drawn character into a jointed **cut-out puppet** for the
KMPMedia library: cut a drawing into transparent part-layers, pin joints, set swing angle/speed/tuck,
pose expression faces, ▶ preview the motion, and export a rig + part PNGs for the library's
`com.solidkey.painpoints.puppet` (`OGPuppet`) primitive.

Single self-contained static page — works offline too (just open `index.html`).

**Live:** https://solidkeyab.github.io/layer-cutter-app/
